# FAIR Statement

This dataset, **ST-OSA-PS-OMT Therapy Dataset**, complies with the FAIR Data Principles to promote Findability, Accessibility, Interoperability, and Reusability of research data.

---

## 🔍 Findable

- **F1**: Metadata and dataset are assigned a globally unique and persistent identifier (DOI: `10.5281/zenodo.1234567`).
- **F2**: Metadata includes rich and contextual descriptions about the dataset's content and purpose.
- **F3**: Metadata clearly and explicitly includes the identifier of the dataset.
- **F4**: The dataset is indexed in a searchable resource (GitHub, Zenodo).

## 🔓 Accessible

- **A1**: Dataset and metadata are retrievable via open standard protocols (HTTP, Git).
- **A1.1**: The dataset is openly accessible without authentication or authorization barriers.
- **A1.2**: Metadata remains accessible even if the data is no longer available.
- **A2**: Licensing and access rights are clearly stated (CC-BY 4.0).

## 🔄 Interoperable

- **I1**: The dataset uses a standard file format (CSV).
- **I2**: Metadata is provided in human- and machine-readable formats (Markdown, CFF, JSON).
- **I3**: Terminologies used align with community standards in clinical and biomedical research.

## 🔁 Reusable

- **R1**: The dataset is well-described and includes documentation to support reuse.
- **R1.1**: Licensing is clear (CC-BY 4.0) to permit reuse.
- **R1.2**: Detailed provenance of the data is provided in `documentation/`.
- **R1.3**: The dataset adheres to domain-relevant standards for clinical study reporting.
